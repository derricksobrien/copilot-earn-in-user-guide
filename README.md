# Copilot Earn-In Academy user guide

[Read the illustrated guide online](https://derricksobrien.github.io/copilot-earn-in-user-guide/).

This public repository contains the October 16, 2026 Simulation MVP guide,
its HTML edition, and 17 supporting screenshots with fictional data.

- [Markdown guide](./USER-GUIDE.md)
- [HTML guide](./index.html)
- [Supporting images](./images/)

This is documentation only, not the application. No sign-in is required to read
this public copy. Access to the simulation itself still requires approval from
its facilitator. Instructions about authenticated documentation refer to the copy
served by the application, not this public site.

Open `index.html` locally with the `images/` folder alongside it for offline
reading, or use your browser's Print / Save as PDF option.

GitHub Pages publishes the root of the `main` branch. Keep image paths relative
when updating the guide.
